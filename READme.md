# News Topic Classification using BERT (Task 1)

## Objective
The goal of this project is to classify news headlines into different categories using a transformer-based NLP model.

## Approach
Instead of training a model from scratch, this project uses a pretrained transformer model to perform zero-shot classification on news headlines.

The model predicts the most relevant topic based on the content of the news text.

## Categories Used
- World
- Sports
- Business
- Technology
- Science

## Methodology
- Loaded a pretrained transformer-based model
- Provided sample news headlines
- Used the model to classify each headline into a topic
- Displayed predicted label and confidence score

## Tools Used
- Python
- Hugging Face Transformers
- Pretrained NLP models

## Results
The model successfully classified different news headlines into relevant categories with confidence scores, demonstrating the power of transformer-based models in NLP tasks.

## Conclusion
This project demonstrates how pretrained transformer models can be used for efficient and accurate text classification without requiring full model training.
